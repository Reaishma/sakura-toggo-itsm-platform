# Unified Enterprise ITSM Simulator

A **web-based Enterprise IT Service Management (ITSM) platform simulator** that demonstrates how modern service desk systems manage tickets, assets, service requests, and operational workflows.

This project combines concepts inspired by major ITSM platforms such as Freshdesk, Zoho Desk, ManageEngine ServiceDesk Plus, and BMC Remedy ITSM into a unified interface.

The simulator recreates enterprise IT support dashboards, ticket workflows, service catalog operations, asset management (CMDB), and SLA monitoring.

---

## Platform Overview

The simulator provides multiple service desk environments inspired by real enterprise tools:

- Freshdesk-style support dashboard
- Zoho Desk multi-channel help center
- ManageEngine ServiceDesk Plus incident and asset management
- BMC Remedy enterprise IT operations dashboard

Each interface demonstrates different operational views used in enterprise IT service management.

---

## Key Features

### ITSM Dashboard
Operational dashboards displaying service desk KPIs including:

- Open tickets
- Resolved tickets
- Average response time
- SLA compliance
- Customer satisfaction (CSAT)
- Agent performance metrics

---

### Ticket Management
Complete ticket lifecycle simulation including:

- Incident Management
- Problem Management
- Change Management
- Service Requests
- Priority classification
- Agent assignment
- Ticket status tracking

---

### Service Catalog
Simulates enterprise service request workflows such as:

- Software installation requests
- Hardware provisioning
- VPN access requests
- Account creation and access management

---

### Knowledge Base
Centralized knowledge repository for troubleshooting guides and support documentation.

---

### Asset Management & CMDB
Tracks IT infrastructure components including:

- Laptops
- Servers
- Networking devices
- Software licenses

This module simulates a **Configuration Management Database (CMDB)** used in enterprise ITSM systems.

---

### SLA Monitoring
Tracks Service Level Agreements including:

- Response time tracking
- Resolution time tracking
- SLA breach monitoring
- Escalation indicators

---

### Reports & Analytics
Operational insights including:

- Ticket volume trends
- Agent workload distribution
- Service performance dashboards
- Incident analytics
